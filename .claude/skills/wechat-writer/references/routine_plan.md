### 前置分析（写入 `01_Plan.md` 固定区块）

#### 文章类型判断（6 选 1）

- **现象解读型**：观察→好奇→研究→升维
- **方法论分享型**：每节必须有可执行动作 + 坦诚说明学习成本
- **产品体验型**：场景演示 + 真实感受
- **调查实验型**：过程叙事 + 层层递进发现
- **工具分享型**：个人故事铺垫→工具展示→效果惊艳
- **读书心得型**：先清晰转述作者观点，再展开个人感触。观点的准确传达是第一优先级。

> 若素材明显属于某类型，大纲重心应向该类型的写法重心倾斜。

#### 内容支柱标注（4 选 1）

- **微习惯实验**: 行为设计、微习惯方法论、习惯养成实验
- **教练体感**: 教练对话反思、个人成长故事、职场体感
- **正念/冥想笔记**: 冥想体感、MBCT 学习、觉察笔记
- **读书分享**: 好书推荐、读后感、书中观点 + 个人触动

> 跨支柱文章选主导情绪的那个。下游视觉导演据此选择侧边栏底色。

#### 选题质检（四维，必做）

- **好奇感**: 有没有一个具体场景、反常识细节或真实问题，让读者想继续看下去？
- **信息增量**: 读者看完能不能多知道一点事实、方法、经验或判断？
- **共鸣感**: 这件事是否能连接到读者自己的处境？
- **读者收益**: 读者读完这篇文章，能带走什么？

> 及格线：至少满足两项。不满足 → 回到 `/interview` 补素材，或请用户确认是否调整角度。

#### 旧文 L1 扫描定位（呼延雷锋）

读 `published_article_index.md` 宽表格，根据系列、标签、关键词定位 2-4 篇相关旧文。**L2 深度对比由李长征在并行阶段执行。**

## 1. 价值主张卡（呼延雷锋）★ 新增

在选题质检通过 + 旧文 L1 定位后，**大纲设计之前**，确定这篇文章对读者的价值主张。这是全文的北极星——大纲和标题都从这里出发。

```markdown
## 价值主张卡

- **写给谁**：[张建国 / 陈思远 / 林小满 / 苏青 / 全向]
  （全向时，后续"什么场景下""什么需求"可拆为 2-3 个短句，每个画像一句）
- **ta 在什么场景下**：[一句话，具体的处境/时刻，让主编能"看到"那个读者]
- **满足 ta 什么需求**：[一句话，ta 在这个场景下的内在驱动力——认知缺口？方法缺失？情绪需要被看见？还是需要找到同路人？]
- **读完能带走什么**：[一句话]
```

### 画像判断参考

基于素材特征 + 选题质检结果 + 旧文 L1 扫描。画像详情 → `knowledge/reader_profiles.md`。

| 文章特征 | 天然匹配画像 |
|---------|-----------|
| 有明确的方法论和步骤 | 张建国 > 陈思远 |
| 有认知框架或系统性洞察 | 陈思远 > 张建国 |
| 有个人挣扎和低谷叙事 | 林小满 > 张建国 |
| 有数据/时间线/量化结果 | 张建国 > 陈思远 |
| 讲的是接纳/放下/自我和解 | 苏青 > 林小满 |
| 正念/冥想/教练/读书心得 | 苏青 > 陈思远 |
| 亲子/家庭/日常生活体感 | 林小满 > 张建国 |

### 价值类型与大权重心

价值主张卡中的"读完能带走什么"暗示了文章的主要价值类型，直接影响大纲的结构重心：

| 价值类型 | 大纲重心 |
|---------|---------|
| 认知升级为主 | 大量篇幅在「揭示盲区」——为什么你之前这样想不对 |
| 方法可操作为主 | 大量篇幅在「怎么做」——具体步骤 + 学习成本诚实说明 |
| 情绪共鸣为主 | 大量篇幅在「你也是这样吗」——场景还原 + 被理解的感受 |
| 深度共振为主 | 大量篇幅在「我也在想这个」——内在过程的诚实记录 |

## 4. 大纲设计（呼延雷锋）

李长征并行工作的同时，呼延雷锋基于价值主张卡设计大纲。

### 大纲每节标注格式

```markdown
### 子标题：XXX

- **推进任务**：[本节承担什么推进任务]
- **价值维度**：[本节帮读者 看到盲区 / 获得工具 / 感到被理解 / 找到同路人]
- **画像钩子**：[本节命中价值主张卡里场景+需求的哪个具体处境/情绪]
- **回扣**：[本节结束时用哪句自然回到核心论点]
- **故事标签**：[障碍]/[行动]/[转折]/[结果]（叙事节标注；非叙事节标注"非叙事"；片段描写标注"片段描写"）
```

### ✨ 闪亮点（必填）

这篇文章最亮的那个瞬间/画面/洞察是什么？（1-2 句）。必须具体——一个画面、一个洞察、一个转折瞬间。禁止写"这篇文章干货很多"。

### 📍 落点（必填）

读者读完最后一段，带走什么感觉？方向性描述，不是口号。例："可以试试这个方法""被理解""重新看待自己那个处境"。

### 主线回扣（必做）

每个中段都要写清楚：本节承担什么推进任务、结束时用哪句回到核心论点。开头埋下的具体细节，结尾是否能以变体形式呼应。

> 目标不是写得更花，而是避免文章变成一堆信息的堆砌。

### 故事标签（叙事节必做）

对涉及完整人物故事的中段标注四要素：`[障碍]` `[行动]` `[转折]` `[结果]`。四要素可不全——若仅为片段描写标注 `[片段描写]`。策划完成后逐节扫描，确保每个故事都有头有尾。

### ⛔ 篇幅-结构联动（必做）

- **< 800 字**: 自由叙事，无需子标题——仅适用于小事件触发型文章
- **≥ 800 字**: 必须设计 1-5 个子标题，每节 300-800 字
- 每个子标题对主话题有明确支撑关系；子标题间逻辑关系清晰
- **结构违规处置**: 大纲预估 ≥ 800 字但未设计子标题结构 → 不得进入 Stage 2

## 5. 汇聚（呼延雷锋）

李长征结果返回后，呼延雷锋做最终汇聚：

1. 将验证过的事实（含来源链接）填入 `01_Plan.md` 的"事实核查表"
2. 基于李长征的 SEO 调研结果，产出 **SEO 决策卡**：

```markdown
## SEO 决策卡

- **状态**: 采用 | weak-signal | skip SEO化
- **标题主词**: ...
- **正文/摘要辅助词**: ...
- **Tags 候选**: ...
- **放置计划**: 标题 / 摘要 / 开头段 / Tags
- **禁用或降级词**: ...
- **备注**: [含"本次是否查了微信指数"标注]
```

### 约束

- Stage 2 / Stage 3 只允许从这里读取 SEO 约束，不直接读取 `SEO_Report.md`
- 若状态为 `skip SEO化`，标题、摘要、正文均不得为了完成流程硬塞关键词
- 若状态为 `weak-signal`，可轻量吸收稳定相关词，但不强制标题承载
- `选题质检卡` 若结论为 `补素材` 或 `调整角度`，不得直接进入 Stage 2
