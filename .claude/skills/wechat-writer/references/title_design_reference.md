## 一、读者画像速查

| 画像 | 会停下来的标题 | 会划过去的标题 | 标题口吻 |
|------|-------------|-------------|---------|
| **陈思远** (惯性困局) | 认知反差——"原来问题不在X，在Y"；信息差——"大多数人没想过" | 纯故事无认知收获、低信息密度、过度承诺 | 信息差在说话——分享一个你没看到的视角 |
| **张建国** (中年转型) | 具体处境词（"脂肪肝""体检""没反弹"）+ 行动暗示（"试了""做到了"） | 空谈感悟不给方法、过于文艺抽象、暗示需大量时间精力 | 同等处境的人在说话——我告诉你我怎么走出来的 |
| **林小满** (改变困难) | 共鸣（"我也是"）+ 低门槛暗示（"没觉得在坚持""不需要意志力"） | 炫耀感、需要强大意志力、大道理 | 过来人在说话——先告诉你"我也是"，再告诉你方法 |
| **苏青** (内在探索) | 诚实、不卖关子、有意象——像日记第一句话 | 任何"你应该"、煽情、黑话（"同频""能量""修行"） | 同路人在说话——分享正在想的、还不确定的 |

> 画像详情 → `knowledge/reader_profiles.md`

## 二、标题人格卡

### 三条锚线

| 锚线 | 检验 |
|------|------|
| **有事件** | 读标题就知道"这篇文章里发生了什么" |
| **有体温** | 能感受到一个活人在说话，不是冷冰冰的观点 |
| **有停顿** | 善用句号、逗号制造呼吸节奏 |

### 三条红线（前两条命中即淘汰，第三条为软性指导）

| 红线 | 典型反例 |
|------|---------|
| 工具化句式 | "X是什么 / 为什么X / 如何X / 你一定要X" |
| 营销腔 | 炸裂、颠覆、干货、底层逻辑、搞定、盘活 |
| 超 35 字 🟡 | 标题控制在 35 字以内，但好标题优先——质量到位时字数可放宽 |

### IP 声音三问

1. 听起来像"实验室日志"还是"导师讲台"？→ 前者通过
2. 有没有"我也在路上"的不完成感？→ 必须有
3. 能不能在四大支柱里找到自然归属？→ 微习惯 / 正念/冥想 / 教练 / 读书分享 / 交叉

## 三、连续性速查（30 秒）

- **句式重复**：最近 3 篇有没有同一个句式？（有 → 换一个）
- **画像偏科**：最近 5 篇同一画像连续出现？（→ 提示下一篇优先锚定其他画像）
- **撞型检查**：与上一篇标题撞型？（连续两篇"不是X，是Y" → 标注）
- **支柱分布**：最近 5 篇支柱分布是否严重偏科？（连续 5 篇同一支柱 → 提示交叉或切换）

## 四、标题生成 3 原则 + 3 步流程

### 3 原则

| 原则 | 问自己 |
|------|--------|
| **对号入座** | 目标读者扫过标题，会不会觉得"这是在说我"？ |
| **回报暗示** | 读标题能感觉到"读完能得到什么"吗？ |
| **星辰声音** | 念出来像在说话还是像在拟标题？ |

### 3 步流程

1. **读价值主张卡 + 闪亮点**：把"写给谁、什么场景、什么需求、带走什么"在脑子里过一遍
2. **写 3-5 个草案**，从不同角度切入（有感觉的多写，没感觉的跳过）：
   - 痛点场景角度 → "又断了？"
   - 读者收获角度 → "有一个方法小到不可能失败"
   - 闪亮点角度 → "每天只做一个俯卧撑"
   - 认知反差角度 → "不是懒，是方法不对"
   - 情绪共鸣角度 → "我也试过一百种方法"
3. **3 原则筛 + 3 红线淘汰** → 选最契合价值主张卡的那条
