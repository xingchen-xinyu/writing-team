# 读者画像 (Reader Profiles)

> **创建时间**: 2026-07-15
> **用途**: 品牌定位的基础锚点。主编 (Stage 1) 锚定目标画像、标题设计 (Stage 3) 画像驱动生成、制作人 (Stage 3) 包装策略，均以此文件为唯一权威来源。
> **设计原则**: 四画像构成个人成长路径（觉察→危机→尝试→深入），不是并列的细分市场。同一读者可能在不同阶段从一个画像过渡到另一个。

## 画像总览

| 画像 | 定位 | 年龄 | 阶段 | 一句话 | 核心需求 |
|------|------|------|------|--------|---------|
| 陈思远 | 惯性困局 | 33 | 觉察危机 | 对现状不满，但被惯性带着走 | 启动点——第一步往哪踩 |
| 张建国 | 中年转型 | 42 | 危机已到 | 上半场跑不动了，下半场不知道往哪跑 | 方向+方法——有人走出来了吗 |
| 林小满 | 改变困难 | 32 | 尝试改变 | 每次努力都坚持不下来 | 更小的一步 + 被看见 |
| 苏青 | 内在探索 | 38 | 深入探索 | 已经在路上，来找同路人 | 深度共振 + 更深的认知 |

### 成长路径

```
觉察危机 → 危机已到 → 尝试改变 → 深入探索
 陈思远  →  张建国  →  林小满  →   苏青
 (看见但没动) (必须动了) (动了但断)  (持续在走)
```

- 陈思远如果不行动 → 五年后就是张建国
- 张建国开始尝试 → 进入林小满的状态（反复断）
- 林小满找到节奏 → 进入苏青（持续深入探索）
- 苏青 → 持续走，没有下一站

## 画像 1：陈思远 — 惯性困局

### 1. 基本信息

| 维度 | 描述 |
|------|------|
| 年龄 | 30-35 岁 |
| 城市 | 一线/新一线（北京、杭州、深圳、成都……） |
| 职业 | 互联网/科技行业中基层，运营/产品/开发。能力不差，但没到不可替代 |
| 收入 | 家庭年收入 25-50 万，有房贷或正在存首付 |
| 家庭 | 已婚或稳定关系。还没孩子，或孩子刚出生不久 |
| 学历 | 本科为主 |
| 信息习惯 | 知识付费重度用户。得到、樊登、混沌都买过。收藏夹里存了几百篇「先马后看」 |

### 2. 现状与困局

**职场层**：每天做的事，说不上讨厌，但肯定不喜欢。一年下来回头看，不知道自己长了什么本事。想换方向，但简历投出去又不知道写什么——这几年到底做了什么？

**学习层**：花了大量时间和钱学习——买课、考证、听书。学的时候觉得醍醐灌顶，学完回到工位上，一切照旧。知识堆在笔记本里，堆在脑子里，就是转化不成行动。

**心理层**：最难受的是「我知道这样不对，但我还在这样做」。每一天都觉得自己在温水里——水温还没烫人，但能看见火在烧。最怕的不是改变失败，是三年后打开手机看到自己还在同一个工位上做同样的事。

**社交层**：朋友圈里有人在创业、有人在旅居、有人在转型。自己还在格子间里。不是嫉妒，是隐隐的恐慌——他们怎么敢的？

### 3. 需求层次

| 层次 | 内容 | 示例 |
|------|------|------|
| 表层需求 | 「告诉我怎么高效学习/时间管理/职业规划」 | 搜索：如何快速读一本书、GTD 方法 |
| 中层需求 | 「让我看到学的东西能转化成什么」 | 点击：有人把知识变成了行动和结果 |
| 深层需求 | 「让我相信改变不需要先成为另一个人」 | 留下：持续关注一个从「一样困住」到「走出去了」的人 |
| 核心驱动力 | **焦虑→行动**。焦虑驱动他寻找，一个可执行的启动点驱动他行动 |

### 4. 内容消费行为

| 维度 | 描述 |
|------|------|
| 阅读时间 | 通勤路上（早 8-9 点）、午休摸鱼（12-13 点）、睡前刷手机（22-23 点） |
| 阅读场景 | 手机，订阅号列表快速滑动。看到「信息增量」类的标题停下来 |
| 点击动机 | 标题里有认知反差（「原来问题不在 X，在 Y」）、信息差（「大多数人没想过」）、可操作的切入点（「试试这个」） |
| 读完动机 | 文章给了他一个「原来可以这样看」的视角转换。不需要完整方法论，需要一个认知升级的瞬间 |
| 收藏动机 | 高——他会收藏「以后可能用得上」的文章。但很少回看 |
| 取关原因 | 纯故事无认知收获、信息密度太低、「就这也好意思写一篇」 |

### 5. 关键词词典

| 类型 | 词汇 |
|------|------|
| 敏感词（吸引） | 惯性、温水、学了很多、转化不了、用不出来、方向、第一步、原来、没想到 |
| 排斥词 | 你必须、只要X就能Y、底层逻辑、赛道、颠覆、干货 |
| 搜索词 | 学了很多但用不出来怎么办、如何找到自己的方向、职业转型第一步 |

### 6. 信任建立路径

```
看到盲区（标题暗示「你之前的理解不够」）
    → 看到视角转换（正文给了新框架）
        → 看到诚实（「我自己也卡在这里卡了很久」）
            → 看到转化（这个人不光在分析，他还做了）
                → 信任建立
```

陈思远对「专业权威」有免疫力——他买过太多课了。他信的不是「这个人很厉害」，是「这个人是真的想过这件事，而且想了很久」。

### 7. 公众号角色定位

你在他的世界里扮演的是**探照灯 + 翻译器**。

- **探照灯**：照出他没看到的盲区——「惯性」「温水」「知识的幻觉」
- **翻译器**：帮他把「我知道」翻译成「我可以做」——把学到的概念转化成行动的第一步
- **不是**：又一个老师（他老师够多了）、成功学导师（他不信那个）、工具人（他要的不是新的效率工具）

### 8. 用户旅程

```
阶段 1: 觉察（"不太对"）→ 看了一篇关于职业倦怠的文章，愣了一下
阶段 2: 寻找（"怎么办"）→ 开始搜相关文章。可能从朋友圈/看一看入口
阶段 3: 遇见（"这个人也经历过"）→ 刷到你的文章，标题有认知反差，点开
阶段 4: 试探（"再看看"）→ 翻历史文章。找那些"他也卡住过"的证据
阶段 5: 确认（"他不是来卖课的"）→ 看到你的文章里有具体的行动和结果，没有推销
阶段 6: 尝试（"那我也试试"）→ 把文章里的一个小方法用了（比如写滋养/消耗清单）
阶段 7: 留下（"持续关注"）→ 长期订阅。他对"同一个人持续成长"的记录有天然兴趣
```

### 9. 不需要的东西

- 纯粹的鸡汤和感悟——他会觉得「浪费了五分钟」
- 需要大量前提条件才能复用的方法论
- 学术引用和理论名词堆砌
- 「你只需要 X 就够了」式的过度简化——他的问题他知道不简单
- 卖课、卖社群、卖咨询

### 10. 典型一天

> 早上 8:20，北京 13 号线。一只手扶着扶手，一只手刷订阅号。手指划过十几条标题，停在一个上：「知道道理是一回事。情绪压过来是另一回事。」愣了一秒——这不就是他吗。道理都懂，但从来不按道理活。点进去，一口气读完。记住了「第二支箭」这个意象。到了公司，上午三个会。午休时又打开那篇文章，发了条仅自己可见的朋友圈：「我也是这样。」晚上睡前，翻开一本买了半年还没拆的书。读了两页，放下。又拿起手机，搜了那个公众号的名字。

## 画像 2：张建国 — 中年转型

### 1. 基本信息

| 维度 | 描述 |
|------|------|
| 年龄 | 40-45 岁 |
| 城市 | 一线/新一线（深圳、广州、杭州、成都……） |
| 职业 | 制造业/传统行业中高层，或大厂/科技公司高龄中层。有一技之长，但行业在下行或自己在下滑 |
| 收入 | 家庭年收入 30-60 万，有房贷，父母可能需要经济支持 |
| 家庭 | 已婚，1-2 个孩子（学龄期）。配偶也有工作压力 |
| 学历 | 本科为主，部分硕士 |
| 健康 | 脂肪肝、高血压、尿酸高——至少中两样。体检报告一年比一年厚 |

### 2. 现状与困局

**身体层**：医生说「要注意了」说了好几年。他也知道该注意——但每天回家已经累到不想动。周末瘫在沙发上刷手机，周一又是循环。

**职场层**：往上走不动，往外跳不敢。行业里做了十几年，人脉、经验都在这一行。但这一行在走下坡。年轻人不懂那么多，但便宜、听话、能加班。自己会的那些东西，好像没那么值钱了。

**家庭层**：老婆也有自己的职业压力。孩子的教育问题越来越复杂——不是简单的「成绩好不好」，是「在这个时代怎么教育孩子」。父母年纪大了，身体开始出问题。他是家里的「顶梁柱」，但这个梁自己也有裂缝。

**心理层**：不是「现在不好」的恐惧，是「不知道还能撑多久」。身体的警告、职场的危机、家庭的压力——三根弦同时绷着。偶尔深夜醒来，盯着天花板想：下半辈子就这样了吗？

### 3. 需求层次

| 层次 | 内容 | 示例 |
|------|------|------|
| 表层需求 | 「告诉我该怎么减肥/转行/调整状态」 | 搜索：中年人怎么减肥、辞职做副业 |
| 中层需求 | 「看到有人跟我处境一样，而且真的走出来了」 | 点击：真实故事 > 方法论文章 |
| 深层需求 | 「让我相信人生下半场不是只有下坡路」 | 留下：持续关注一个正在走的人 |
| 核心驱动力 | **恐惧→希望**。恐惧驱动他来，希望驱动他留下 |

### 4. 内容消费行为

| 维度 | 描述 |
|------|------|
| 阅读时间 | 通勤地铁（早 7-8 点）、午休（12-13 点）、深夜（22-23 点，孩子睡了之后） |
| 阅读场景 | 手机，订阅号列表快速滑动。标题里有他的处境词 → 停下来 |
| 点击动机 | 标题里有具体处境（"脂肪肝""中年""每天都很疼""上坟"）+ 有行动暗示（"试了""没反弹""做到了"） |
| 读完动机 | 文章里有具体方法、有可复制的路径、有真实的数据变化（时间线、数字、前后对比） |
| 分享动机 | 低。他很少分享个人成长类文章——这是他自己的事，不想让别人知道他在看 |
| 取关原因 | 连续几篇「只是在讲感悟没什么可用的」；过度营销卖课；文章写得越来越像成功学 |

### 5. 关键词词典

| 类型 | 词汇 |
|------|------|
| 敏感词（吸引） | 中年、体检、脂肪肝、减肥、没反弹、做到了、方向、改变、下半场、上半场、撑 |
| 排斥词 | 躺平、认命、就这样吧、你必须、一定要、赛道、底层逻辑、颠覆、干货 |
| 搜索词 | 中年危机怎么办、减肥不反弹的方法、辞职做副业、40 岁还能转行吗 |

### 6. 信任建立路径

```
看到自己（标题对号入座："这就是我"）
    → 看到同类（开头"我也是"的感觉）
        → 看到结果（这个人是真的做到了——数据/时间线做证）
            → 看到方法（具体、可复制、不需要特殊条件的方案）
                → 看到诚实（"我也还在路上"，不是全好了）
                    → 信任建立
```

张建国的信任不是「这个人很专业」，是「这个人不装，他说的话我能信」。

### 7. 公众号角色定位

你在他的世界里扮演的是**镜子 + 地图**。

- **镜子**：让他看到「我不是唯一一个这样的」
- **地图**：告诉他「有人从这里走到了那里，路是这样的」
- **不是**：导师（他不需要被教）、同伴（你们不认识）、偶像（他学不来）

### 8. 用户旅程

```
阶段 1: 意识（"不对劲"）→ 体检报告亮了红灯 / 公司又裁了一批
阶段 2: 寻找（"怎么办"）→ 开始翻公众号、听播客、看视频
阶段 3: 遇见（"这个人懂我"）→ 刷到你的某篇文章，停下来
阶段 4: 试探（"先看看"）→ 翻历史文章，挑 2-3 篇读，确认"这个人是真的"
阶段 5: 相信（"他是真的"）→ 看到时间线和数据，确认不是编的故事
阶段 6: 尝试（"我也试试"）→ 把文章里的方法用了 1-2 次（比如微习惯拆解法）
阶段 7: 留下（"继续关注"）→ 长期订阅。偶尔留言。不太分享，但会持续看
```

### 9. 不需要的东西

- 纯理论或学术引用——「说点人话」
- 需要大量时间/金钱才能启动的方案——他两个都缺
- 「想开点」「心态好就行」式的空洞安慰——不是不想想开，是想了也开不了
- 成功学式的打鸡血——他过了那个年纪了
- 贩卖焦虑——他已经够焦虑了，不需要你加柴

### 10. 典型一天

> 早上 6:50 起床，昨晚又没睡好。匆匆吃完早餐，开车去公司——今天限行，绕了二十分钟。路上听了一段播客，没听完就到了。上午三个会，下午两个。中午吃饭时掏出手机刷订阅号，手指快速滑动。一个标题停住了：「肿瘤两年没长大，靠的不是药，是这三件事。」点进去，一口气读完。记住了「微习惯」三个字。心里想：这个人跟我差不多年纪，他也经历过。收藏了。晚上 10 点，孩子睡了。打开电脑——不是加班，是打开那个公众号看了第二篇。看完想了想，又看了第三篇。

## 画像 3：林小满 — 改变困难

### 1. 基本信息

| 维度 | 描述 |
|------|------|
| 年龄 | 30-35 岁 |
| 城市 | 一线/新一线（上海、成都、杭州、深圳……） |
| 职业 | 设计师、文案、运营、产品——有一定创意成分的工作。工作本身不讨厌，但总觉得「好像不是这个」 |
| 收入 | 家庭年收入 20-40 万。有房贷或租房压力 |
| 家庭 | 已婚，可能有幼儿。婆媳/原生家庭关系是常见压力源 |
| 学历 | 本科为主 |
| 尝试史 | 健身卡 3 张（去不到 10 次）、收藏 100+ 篇「改变自己」一篇没翻第二次、报过至少一个线上课程没学完 |

### 2. 现状与困局

**执行层**：每次开始的时候，热情很高。买装备、做计划、发朋友圈：「从今天开始！」一周后——没了。不是「不想」了，就是某天忘了，然后第二天也忘了，然后觉得「算了反正断了」。

**心理层**：最伤的不是断了一次——是断了太多次之后，开始相信一个结论：「可能我就是这种人。」一旦接受这个结论，就不再尝试了。不尝试不是因为懒，是因为不想再失望一次。

**比较层**：她能看到别人在变好。朋友圈里有人在跑步、有人在读书、有人在减肥、有人在创业。她不是嫉妒，她是困惑——「他们是怎么做到的？他们也像我一样，每天回到家就想躺下吗？还是只有我？」

**自我叙事层**：「我试过了」——这四个字是她的护身符。但这个「试过了」往往只试了一次，或者只试了三天。她需要的是一个能让她在「试第三天」的时候不会觉得「已经没用了」的东西。

### 3. 需求层次

| 层次 | 内容 | 示例 |
|------|------|------|
| 表层需求 | 「告诉我怎么坚持下去」 | 搜索：如何养成习惯、自律的方法 |
| 中层需求 | 「让我看到原来不是我一个人这样」 | 点击：有人跟我一样反复失败，但他找到了方法 |
| 深层需求 | 「让我重新相信自己是可以改变的」 | 留下：持续看到同一个人从不行到行的过程 |
| 核心驱动力 | **挫败→信心**。挫败感驱使她来，被看见+小成功驱动她留下 |

### 4. 内容消费行为

| 维度 | 描述 |
|------|------|
| 阅读时间 | 通勤路上（早 8-9 点）、午休（12-13 点）、睡前刷（22-23 点）、周末早晨赖床时 |
| 阅读场景 | 手机为主。喜欢看「真实的人写的真实的事」 |
| 点击动机 | 标题有共鸣（"我也这样"）+ 低门槛暗示（"没觉得在坚持""不需要意志力""试了一种"） |
| 读完动机 | 文章里有具体的画面和体感——不是抽象道理。读完后感觉「这个人跟我一样」，同时有「但她的方法好像我也可以试试」 |
| 转发动机 | 中高。她愿意转发到朋友圈——「你看，不只是我这样」 |
| 取关原因 | 文章开始说教、炫耀、居高临下。或者连续几篇内容跟她生活完全不相关 |

### 5. 关键词词典

| 类型 | 词汇 |
|------|------|
| 敏感词（吸引） | 坚持不了、半途而废、又断了、我也是、没觉得在坚持、不用咬牙、小到不可能失败、原来不是我 |
| 排斥词 | 自律、意志力、管住自己、你一定要、只要坚持就能、底层逻辑、蜕变 |
| 搜索词 | 怎么坚持一个习惯、为什么总是半途而废、有没有不用自律的方法 |

### 6. 信任建立路径

```
看到共鸣（标题说中她的状态："我也这样"）
    → 看到画面（开头有具体的场景/体感，不是道理）
        → 看到「不是你不行」（文章说清"为什么你会这样"——是方法不对，不是你懒）
            → 看到方法（一个极低门槛、几乎不可能失败的方案）
                → 看到「还在路上」（作者自己也还在做，不是"全搞定了在教你"）
                    → 信任建立
```

林小满的信任不是「这个人比我强」，是「这个人懂我，而且她没放弃我」。

### 7. 公众号角色定位

你在她的世界里扮演的是**过来人 + 啦啦队**。

- **过来人**：「我以前也做不到」——这个开场比什么都重要
- **啦啦队**：不是喊"加油"，是用具体的方法让她看到「这一步小到不会失败」
- **不是**：成功榜样（距离太远反而让她更沮丧）、教练（"你应该"的感觉不好）、闺蜜（你们不认识，但你的文字可以像闺蜜）

### 8. 用户旅程

```
阶段 1: 受挫（"又断了"）→ 一个习惯尝试又一次中断。躺沙发上刷手机
阶段 2: 遇见（"她说的是我"）→ 刷到一篇文章，标题像在说她。点开，发现开头写的跟她的经历一模一样
阶段 3: 释然（"原来不是我一个人"）→ 读到作者也有同样的挣扎，不是「天生自律的人」
阶段 4: 好奇（"她是怎么做到的"）→ 读到具体的方法——而且这个方法很简单
阶段 5: 尝试（"这个我可以"）→ 试了文章里的一个小方法——门槛很低，没有什么压力
阶段 6: 惊喜（"这次没断！"）→ 竟然坚持了一周。她不觉得「厉害」，她觉得「原来方法对了」
阶段 7: 留下（"继续跟着"）→ 长期订阅。她是转发意愿最高的画像——想告诉别人「不是因为我不行」
```

### 9. 不需要的东西

- 「你只要坚持就行了」——这话她听够了
- 需要大量意志力的方案——她没有多余的意志力可以花
- 成功学——「从今天起做一个全新的自己」——她信过一次，没用了
- 责备——任何让她觉得「我就是不行」的表述，哪怕是无意的
- 太复杂的理论——她不是来学习的，是来找一条能走的路

### 10. 典型一天

> 早上 8:15，上海 2 号线。人太多，手机举到眼前。刷到一篇文章：「减肥有一百种方法。我试了一种，没觉得自己在坚持。」愣了一下——她昨天刚放弃了坚持了三天的「16+8」。点进去，看到作者说自己也试过各种方法，都失败了。最后用一种「小到不可能失败」的方法瘦了十几斤。「每天只做一个俯卧撑」——她觉得荒谬，但也觉得「这个我好像真的可以」。晚上回到家，试了一个俯卧撑。做完了。又做了五个。第二天早上，她没发朋友圈。但心里有个很小的声音：再做一下试试。

## 画像 4：苏青 — 内在探索

### 1. 基本信息

| 维度 | 描述 |
|------|------|
| 年龄 | 35-42 岁 |
| 城市 | 不限。一线到三线都有可能。已经在自己的节奏里，不太被城市定义 |
| 职业 | 多元——可能是自由职业、已转型、半退休，或仍在职场但心态已不同。工作不再是生活重心 |
| 收入 | 家庭年收入 20-50 万。物质需求在降低，追求的不再是更高薪水 |
| 家庭 | 已婚或有稳定关系。孩子可能已经比较大，或选择不生育 |
| 学历 | 本科以上，阅读量大 |
| 内在履历 | 长期练习正念/冥想、参加过教练课程、做过心理咨询、有定期的自我反思习惯。内在探索不是「最近开始的」，是已经走了几年 |

### 2. 现状与困局

**外在层**：外在的改变已经发生或正在进行——生活方式、工作节奏、关系模式，已经跟几年前不一样了。不太焦虑生存问题。不是「没烦恼」，是烦恼的性质变了——不再是「怎么办」，是「为什么」「还要往哪」。

**内在层**：开始在更深的地方提问——「我到底在干什么」「是什么在驱动我」「什么是足够」。这些问题没有标准答案。但以前可以不问，现在绕不过去了。

**孤独层**：身边的人不一定能聊这些。有时候读完一本书或做完一次冥想，有深刻的触动——但不知道该跟谁说。说出来别人可能觉得「你想太多了」。

**表达层**：可能需要一个出口。不是写给别人看——是把内在的探索过程记录下来。你的公众号对她来说不只是阅读，是一个镜像：看到有人在记录同样的旅程。有时候她会在留言区写很长的话——因为她觉得你能懂。

### 3. 需求层次

| 层次 | 内容 | 示例 |
|------|------|------|
| 表层需求 | 「推荐一本有关内心的好书」「冥想到底怎么练」 | 搜索：MBCT 课程、正念书籍推荐 |
| 中层需求 | 「让我知道我不是唯一在路上的人」 | 点击：有人以同样的诚实记录了内在历程 |
| 深层需求 | 「让我看见自己还没看见的东西——内心的下一个房间」 | 留下：持续读一个正在探索的人的真实记录 |
| 核心驱动力 | **孤独→共振**。独自行走的孤独驱动她来，找到同路人驱动她留下 |

### 4. 内容消费行为

| 维度 | 描述 |
|------|------|
| 阅读时间 | 早晨安静时（6-7 点，冥想后）、周末有大段时间时、深夜（有情绪触动时） |
| 阅读场景 | 不在地铁上读。在沙发、床上、咖啡馆——需要安静。更可能从朋友圈/看一看/推荐进入 |
| 点击动机 | 不是钩子驱动——她反感「钩子」。标题里有真实的情感和不装的语气（"说不上为什么""可能""还在路上"），比「你一定要知道」更吸引她 |
| 读完动机 | 文章里有真实的内心过程——不是结论，是「我在想……我试了……我也不确定」。给她一个意象/隐喻/框架，让她能带回去想自己的事 |
| 留言动机 | 中高——她是最可能在文章下面写长留言的人。不是因为感动，是因为「这个问题我也在想」 |
| 取关原因 | 文章突然开始卖焦虑、标题党、内容变浅——追求传播而牺牲深度 |

### 5. 关键词词典

| 类型 | 词汇 |
|------|------|
| 敏感词（吸引） | 发现自己、内心、停下来、不知道、可能、或许、慢慢、说不上为什么、有一次、我在想、在路上的 |
| 排斥词 | 搞定、快速、终极、揭秘、成功、你必须、改变人生的、颠覆 |
| 搜索词 | MBCT 课程哪里学、正念冥想入门、人生教练怎么找、心灵类书单 |

### 6. 信任建立路径

```
看到诚实（标题不卖关子——就是在说一件真事）
    → 看到过程（正文有个人的内心过程，不是结论）
        → 看到深度（有意象/隐喻/框架，不是流水账）
            → 看到「还在走」（不是"我找到了答案"，是"我还在找，而且记录下来了"）
                → 信任建立
```

苏青的信任不是「这个人知道答案」，是「这个人诚实，而且他想的深度是认真的」。

### 7. 公众号角色定位

你在她的世界里扮演的是**同路人 + 探路者**。

- **同路人**：「我在走的路上遇到了你，你也在这条路上」
- **探路者**：你比她多走了几步——你记录下来的东西，她可能还未命名但已经开始感受
- **不是**：导师（在内在探索这条路上，没有导师）、榜样（你的状态不是她的目标）、出口（她不依赖你，她有自己的内在资源）

### 8. 用户旅程

```
阶段 1: 已经在路上 → 她已经有内在探索的习惯（冥想/读书/教练/写作）
阶段 2: 偶然遇见 → 从某个同频的渠道（朋友转发/同类文章推荐）看到你的文字
阶段 3: 被触动 → 某篇文章说到了她正在想但没说清楚的东西——「原来可以这样描述」
阶段 4: 翻回去读 → 翻历史文章，不是检查真假（她不需要数据验证），是感受深度是否一致
阶段 5: 建立连接 → 关注，可能留言说一段自己的经历和反思
阶段 6: 成为日常陪伴 → 不是每篇都看，但出新篇会点进去。像定期见一个朋友
阶段 7: 内在对话 → 她把你的文章当做个人反思的触发点。不是「他说了什么」，是「这让我想到了什么」
```

### 9. 不需要的东西

- 任何形式的「你应该」「你要相信」「你做得到」——她不需要被鼓励
- 方法论包装——她已经有自己的框架，不是来找方法的
- 「同频」「能量」「修行」——这类圈子黑话
- 过度煽情——真诚的触动和刻意的煽情，她能一眼分辨
- 把内在探索包装成「成功」或「觉醒」——她不信那种叙事

### 10. 典型一天

> 早上 6:15，自然醒。做了半小时冥想。泡了杯茶，坐在窗边。打开微信，看到关注列表里那个公众号更新了——「心不是用来修的。是用来陪的。」读完，停了很久。书架上有一本翻了一半的《正念静观繁盛之路》，拿下来继续读。中午没约人，自己做了顿饭。洗碗的时候脑子里还在转那篇文章里的那句——「你不缺友善。你只是没用在自己身上。」用一个下午的间隙写下了一小段自己的笔记：「我对我自己，有时候比对别人还狠。我跟一个最好的朋友，这两年才刚开始说话。」存了草稿，不知道什么时候会发。不重要了——重要的是写下来的时候，手是稳的。

## 画像使用指南

### Stage 1 策划时

主编（呼延雷锋）根据素材特征，判断本文主目标画像，写入 `01_Plan.md` 的「目标画像锚定」字段：

```markdown
## 目标画像锚定
- **主目标画像**: 张建国（中年转型）
- **为什么是他/她**: [一句话：素材中的什么特征指向这个画像]
- **画像类型**: 单一画像 / 全向
```

**画像-文章天然匹配速查**：

| 文章特征 | 天然匹配画像 | 说明 |
|---------|-----------|------|
| 有明确的方法论和步骤 | 张建国 > 陈思远 | 转型群体最需要"怎么走" |
| 有认知框架或系统性洞察 | 陈思远 > 张建国 | 惯性困局最需要"怎么看" |
| 有个人挣扎和低谷叙事 | 林小满 > 张建国 | 改变困难最需要"你也这样" |
| 有数据/时间线/量化结果 | 张建国 > 陈思远 | 转型群体最信"真有结果" |
| 讲的是接纳/放下/自我和解 | 苏青 > 林小满 | 内在探索最需要深度共振 |
| 纯个人体感无明显方法指向 | 林小满 > 苏青 | 张建国容易划过去 |
| 正念/冥想/教练/读书心得 | 苏青 > 陈思远 | 内在探索最需要认知深度 |
| 亲子/家庭/日常生活体感 | 林小满 > 张建国 | 改变困难最需要被看见 |

采用画像驱动标题生成（详见 `references/title_design_reference.md`），以本文件画像为唯一锚定来源。标题生成在 Stage 3 由主编执行：读取价值主张卡 → 3 原则 · 3 红线 · 3 步流程。
