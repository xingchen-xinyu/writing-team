# 星辰写作风格指南 (Style Guide)

> **Core Tone**: 真诚、自然、有温度。
> **Archetype**: 像一位踩过坑的朋友在饭桌上掏心窝子聊天，偶尔切换成有研究精神的探索者在记录实验过程。不卖课，不推销，只分享真实验证过的经验和方法。

## 1. 核心基调 (Tone & Voice)

*   **真诚 (Honest)**: 分享自己真实验证过的方法和体验。不假装权威，不掩饰踩过的坑。读者能感受到这个判断是认真想过的。
*   **自然 (Natural)**: 像跟朋友聊天一样说话，不过度精炼打磨。读出来应该像语音转文字，而不是演讲稿。不端着，不说教，不写"教科书"。
*   **有温度 (Warm)**: 情绪表达来自体感记忆（"我当时就愣住了"），而非知识性描述。拒绝理中客的中立感，该说"惨不忍睹"时不说"效果不佳"。
*   **叙事视角**: 第一人称"分享体验"，而不是第三方"报告事实"。相信读者的感受力，避免对显而易见的情感和逻辑进行过度解释。

### 1.1 口语梯度

全文以**B 级**为默认语气。**C 级**只在关键场景和情绪转折点使用。

| 层级 | 密度 | 用途 | 示例 |
|------|------|------|------|
| **B 级（基底）** | 正常叙事节奏，允许口语语序，有停顿感 | 全文默认语气 | 「室内泳池早上九点开门，我那会儿一般都到了，经常就我一个人。」 |
| **C 级（调味）** | 更高细节密度，感官沉浸，场景感强 | 关键场景、情绪转折点 | 「我们家附近那个室内泳池，早上一开门我就到，连救生员都认识我了。」 |

**使用规则**：
- B 级为全文默认语气。检验：朗读一段，听起来像说话而不是读稿，即通过。
- C 级不超过全文 20%，否则变啰嗦。只在需要读者"看到画面"的关键时刻使用。
- 关键判断：删掉一句话后，缺的是信息还是文采？只加文采没信息——删；补充了场景细节或情绪层次——留。

### 1.2 节奏控制

- 长句和短句交错，避免连续 3 句以上同样长度的句子
- 每段开头不要总是「我」字开头，变换主语和句式
- 段落之间允许跳跃感，不需要每段都写承上启下的过渡句
- 允许一句话独立成段（全文 2-3 次），制造停顿和呼吸

### 1.2.1 语流密度

检验标准：从正文中随机截取连续 5 句，统计其中有多少句可以**独立成义**（不依赖前句也能完整理解）。

- 5 句中 ≥ 4 句独立成义 → 节奏过紧，像演讲稿
- 5 句中 2-3 句依赖前句才能完整理解 → 语流正常，像聊天
- 目标：至少有一两句读起来不像"写完的"，而像"正在说的"

**操作指南**：如果发现连续多句都独立成义，做两件事：
1. 找到相邻两句，把句号改成逗号，让后一句变成前一句的延伸
2. 找到一句"结论型"短句，在前面加口语过渡（"你想想看""说句实话""有意思的是"）

**示例**：
- 改前（4/5 独立成义）：「我学教练四五年了。生活中还是经常不自觉切到一层。聚光灯一不小心就打向了自己。本能的力量太强大了。不只是教练对话和静观探询。」
- 改后（2/5 独立成义）：「我学教练四五年了，说句实话，生活中还是经常不自觉切到一层，自动化聆听，聚光灯一不小心就打回到自己身上。你问我为什么？本能的力量太强大了。不只是教练对话和静观探询，日常聊天也一样。你试试看就知道了。」

## 2. 用词禁忌 (Negative List)

**严禁**使用以下情绪化、营销味重或动作感过强的词汇：

| 禁止词汇 | 推荐替换 | 原因 |
| :--- | :--- | :--- |
| **死磕** | 继续完善 / 多尝试一下 | 过于用力，不从容 |
| **搞定** | 解决了 / 处理好了 | 过于随意，缺乏质感 |
| **炸裂** | 很惊讶 / 印象深刻 | 营销号味道太重 |
| **盘活** | 整理 / 利用起来 | 过于商业化 |
| **干货** | 经验 / 心得 | 过于功利 |
| **痛点** | 麻烦 / 问题 | 互联网黑话 |
| **底层逻辑** | 原理 / 原因 | 互联网黑话 |
| **颠覆** | 改变 / 影响 | 夸大其词 |

## 3. 细节补充权限 (Expansion Permissions)

在忠于原文核心事实的基础上，**授权**适度补充以下细节，以增强文本的质感和真实感：

*   **✅ 允许补充**:
    *   **动词具体化**: "弄好了" → "把松动的螺丝拧紧了"。
    *   **环境渲染**: "在咖啡馆" → "在常去的那家咖啡馆，背景是淡淡的咖啡香"。
    *   **内心活动**: "有点担心" → "心里盘算着万一不成怎么办"。
    *   **感官细节**: 增加视觉、听觉、嗅觉的描写。

*   **❌ 禁止补充**:
    *   新的人物。
    *   新的情节转折。
    *   原文未提及的数据或案例。
    *   超出原文结论的推断。

**检验标准**: 补充后，让原作者读，他不能发现任何"我没做过/没想过"的新信息，只能感觉"这正是我当时的感受，只是你写得更细致了"。

## 4. 人机协作边界 (Human-AI Boundary)

写作时要始终区分三类材料：

*   **星辰必须亲自提供的**：第一手经历、关键情绪、人物关系、核心判断的来源。
*   **AI 可以辅助的**：背景资料、事实核查、类比候选、结构建议和表达润色。
*   **绝对不能补的**：星辰没经历过的故事、没说过的观点、没验证的数据，以及为了让段落更"像真的"而编出来的细节。

**检验标准**：如果一句话删掉后只少了一点文采，但保住了真实性，宁可删掉。

## 5. 口语词库 (Colloquial Vocabulary)

为了承载"真诚、自然、有温度"的调性，请在需要转场、表达观点或拉近距离时，主动且自然地使用以下词组（不要强行堆砌，需符合语境）：

*   **转场与铺垫**："说句心里话"、"其实很多时候"、"坦率地讲"、"顺着上面的再聊聊"、"很有意思的是"。
*   **表达判断**："我自己的感受是"、"我一直觉得"、"不是说xxx不行，而是说"。
*   **拉近距离**："很多朋友可能不知道"、"你如果关注过这个领域"、"大家也都知道"。
*   **承认与自嘲**："说实话我也不确定"、"这个坑我也踩过"、"可能有些想法还不成熟"。
*   **语流连接**（让句子之间靠气息连着，不靠句号断开）："就是那种……你知道吧"、"我也说不太清楚，但大概意思是……"、"你想想看"、"这个感觉挺奇怪的"、"回头想的话"、"有意思的是"、"说不上为什么，就是……"、"可能你也经历过"。

> **注意**：以上为初始参考词库。随着写作实践，请用自己真正会说的口头禅逐步替换。

## 6. 高级写作手法 (Advanced Techniques)

*   **谦逊铺垫法（柔性建议）**：在写建议类内容或教程方法论时，不要摆出一副"教你做事"的傲慢姿态。**核心原则：先承认学习成本和失败点**。具体措辞由主笔判断，比如"一开始可能会有点笨拙"、"不知道对大家有没有用"，通过真实的"不确定感"来降低读者的防御心。
*   **逐一展示法（升番逻辑）**：当涉及多个案例、产品或方法时，**尽量避免一次性罗列（Bullet Points）**。要像讲相声一样，一个一个抛出来，每个都带一句独特的点评或吐槽，制造情绪的层层递进和惊喜感。**（注：纯技术教程的操作步骤或清单类内容除外，此类场景仍可使用列表以保证清晰度）**。
*   **主线回扣法（防跑偏）**：每一节可以展开故事、案例或知识，但结尾要用一句自然的话回到核心论点。好的回扣不需要喊口号，只需要让读者知道："原来这一段还是在讲同一件事。"
*   **回环呼应法（作品感）**：开头出现过的一个动作、画面或问题，结尾尽量以更从容的视角回应一次。这样文章会像一段完整的经历，而不是材料拼贴。
*   **感官描写优先于抽象概念**：涉及精神性、信仰或内心体验时，优先用视觉、听觉等感官意象表达，而不是直接使用宗教术语或抽象概念。比如"河的前方发着金光"比"河的前方是佛祖的方向"门槛更低，不同背景的读者都能进入画面——但不要为了普世把个人色彩抹掉。
*   **从"我"到"我们"的升华转向**：在文章升华段落，避免停留在"我发光了"的个人叙事。自然过渡到关系和连接——"大家都在发光，互相影响着对方"。这和「爱和慈悲」的核心价值观一致，让升华不空洞。

## 7. 开头与结尾技巧（参考）

### 开头五种必杀技

永远从一个具体的、当下的事件或场景切入，绝不宏大叙事：

1. **叙事启动**："故事是这样的。" / "事情是这样的。" 简单直接。
2. **荒诞事实**：直接抛出一个让人"？？？"的事实。
3. **热点破题**："最近这两天，被 XXX 刷屏了。"
4. **好奇心驱动**："这两天在网上刷到一张图，很有意思。"
5. **痛点切入**：从一个所有人都感同身受的日常痛点直接拉入。

### 结尾六种收法

1. **引用收尾**：用别人的一句话作结（"XX 说：磨平一些信息差"）
2. **哲思余韵**：一个短句留白（"时间。流逝的本身。"）
3. **行动呼吁**：鼓励读者去做一件事
4. **信念宣言**：表达对未来的坚信
5. **回环呼应**：回到开头的意象，但视角已经不同
6. **自然收束**：不升华不拔高，就停在该停的地方
7. **画面收束**：给出完整的画面后直接收住，不给评价。比如"铺满了整个宇宙。"就够了，不需要再加"无比壮观"。读者能自己感受到的东西，替他说出来反而削弱力量。

> 这些是参考，不是强制。关键是：结尾要有收束感，不能戛然而止，也不能写成"综上所述我们应当"。

## 8. 体感叙事的五个锚点 (Sensory-Storytelling Anchors)

适用于个人体感/哲学反射型文章。每一条都有检验方式。

### 8.1 感官锚：关键场景必须有感官细节

文章最重要的那个场景（通常是开头），至少给出一个视觉、听觉或触觉细节，让读者**感受到画面**而不只是知道发生了什么。

- **反例**：「慧芳老师把诗分成七小段，每人读一段。然后她用台湾口音完整读了一遍。」→ 场记，只有信息没有画面。
- **正例**：「她带着台湾女生那种软软的口音，像把诗裹在一层纱布里递过来。」→ 有听觉意象。
- **检验**：删掉这句话，少了的是信息还是画面？如果只是信息，就没到位。

**⛔ 当心感官锚变成填空题**：

感官锚不是每篇文章、每个场景的必填项。它的价值取决于场景本身——如果原始素材里没有值得展开的感官记忆，保持简洁就是最好的写法。

- **正例（不加也成立）**：「早上读书，读到一句话。很普通的一句话，但我停了下来。」→ 干净有力，不需要补「手里的书还停在那一页」。
- **反例（硬加）**：「早上读书，读到一句话。手里的书还停在那一页，没翻过去。」→ 加了一个不承载任何情绪的细节，读者感觉你在交作业。
- **判断标准**：这个场景如果加感官细节，能不能让读者更接近我当时的感觉？如果不能——不加。
- **底线**：补不出来的东西硬补就是造假。感官锚是对已有素材的检验框架，不是对缺失素材的生成指令。素材里没有的感官记忆，宁可留白也不要编。

### 8.2 隐喻锚：引入外部参照物后必须长出你自己的变体

借用一首诗、一本书、一个概念时，不能只把它**用**在文章里。必须至少在一个地方**推开它**，给出你自己的变体命名。

- **反例**：鲁米说「客栈」→ 正文反复说「客人」「走进来的客人」→ 停留在原隐喻框架内。
- **正例**：鲁米说「客栈」→ 长出自己的「拆家 / 搬家」→ 读者记住的是你的东西。
- **检验**：读完后，读者能复述出的那个核心意象，是原作者的还是你的？

### 8.3 思考感：用「正在想」替代「想好了」

个人体感的竞争力不是结论正确，而是**读者感觉你在跟他一起想**。

- **反例**：「回头看这段路，我从 A 到 B 再到 C，最后 D。」→ 结论感，像 PPT 总结。
- **正例**：「后来很多时候我都在想…」「有意思的是，它们来的时候你不知道…」「这里头有一件事我想诚实地讲。」→ 思考感，像边想边说。
- **禁用句式**：列举式总结（「从…到…再到…最后…」）、阶段性编号（「第一阶段…第二阶段…」）。这些在个人体感文中会杀死思考感。

### 8.4 节奏锚：句子长度跨度要够大

不是有没有短句的问题，是**最长句和最短句之间的跨度**。

- **反例**：全文句子都在 8–20 字范围内波动 → 节奏平。
- **正例**：「向导。」（2 字独立段）→ 「一段让你每天上班前要做心理建设的处境，是向导。」（20+ 字舒展句）→ 跨度拉出来了。
- **目标**：全文至少出现 1 次 5 字以内的独立段，和 1 次 30 字以上的舒展长句。二者的**间距**越近，节奏张力越大。

**舒展型长句 vs 解释型长句**：

- 解释型长句靠逻辑词连接（因为/所以/如果/当……时）→ 像在说明
- 舒展型长句靠思绪自然流淌（中间没有"因为所以"，只有画面和感受的连续铺展）→ 像在聊天

**反例（解释型）**：「如果你听着听着，脑子里已经在组织下一句要说什么，那么你就在第一层。」
**正例（舒展型）**：「那段时间每天早上起来，做完蝴蝶展翅，感觉到大腿两侧那种熟悉的撕裂感，我就会想——这件事已经做了两年了，每天都很疼，但说不上为什么，就是不想停。」

**检验**：删掉这句话后少的是逻辑推导还是情绪/画面？前者是解释型，后者是舒展型。全文至少有 1 次舒展型长句。

### 8.5 读者锚：结尾必须有转向读者的时刻

个人叙事型文章的结尾分两层——先说**我的事**，然后说**你的事**。

- **反例**：「闭上眼，慧芳老师的声音还在耳边。我知道那个向导要带我去哪儿了。」→ 停在自我，读者被留在外面。
- **正例**：「如果你也在一段低谷里，可能这首诗现在还帮不了你什么。没关系。把它放在那里。等你哪天回头看…」→ 给了读者一个位置。
- **注意**：不是每篇文章都要这样做。但如果文章的主旨是「希望读者也能这样看待痛苦」，那结尾不转向读者就是落空了。

### 8.6 氛围感三技法

适用于需要让读者"置身现场"的关键场景——开头的场景还原、教练对话的还原、冥想体感的描写。

#### 技法 1：感官描写——不只写"发生了什么"，写"感受到什么"

- **基础**：「我们坐在会议室里聊了两个小时。」
- **有氛围**：「会议室空调有点冷，他说话时不停搓手臂。两个小时后我才发现自己的咖啡一口没喝。」
- **检验**：删掉这句话后，少了的是信息还是身体感受？如果只是信息，就没到位。

#### 技法 2：情绪渲染——让读者感受情绪，而不是被告知情绪

- **基础**：「我当时很焦虑。」
- **有氛围**：「手机响了就心跳加速，拿起来才发现不是微信，只是天气推送。」
- **检验**：文中有没有"我很XX"这种直接宣告情绪的句子？有就换成具体反应。

#### 技法 3：节奏控制——用句子长度制造呼吸感

- **紧张/焦虑场景**：用短句，让读者感受急促（「打腿。转头换气。划手。」）
- **放松/沉思场景**：用舒展长句，让读者跟着慢下来
- **转折点**：一句超短句独立成段（2-5 字），制造停顿和重量感

## 9. 主笔工具箱（冰清速查）

### 9.1 框架公式速查

帮助理解主编的大纲结构逻辑：

| 框架 | 结构 | 适用场景 |
|------|------|---------|
| 并列式 | 多个并列观点展开 | 多个独立论点各自陈述 |
| 对比式 | 正反对比凸显观点 | 有明确的"A vs B"张力 |
| 递进式 | 由浅入深，层层推进 | 从现象→原因→反思→行动 |
| SCQA | 情境→冲突→问题→答案 | 需要先让读者"感同身受"再给出方案 |

### 9.2 减法写作清单

写完初稿后自查：

- [ ] 有没有连续两句表达同一个意思？→ 删掉弱的那句
- [ ] 有没有"然而/但是/不过"开头但前后意思差不多的句子？→ 合并
- [ ] 有没有一个观点用了两个例子但第一个已经够了？→ 删掉第二个或大幅精简
- [ ] 有没有对显而易见的感受做解释？（如"这让我感到很难过"） → 删掉解释，只留感受本身
- [ ] 有没有在大纲之外加塞的"顺便说一下"段落？→ 砍掉，回归主线

### 9.3 开头/结尾手法速查

扩展自现有 §7，保留原有内容的基础上补充：

**开头补充手法**：
6. **反差切入**：先说结果，再倒叙原因（"那是我第一次觉得，这份工作可能做不下去了。在那之前的三年，我一直是部门绩效最好的那个。"）
7. **细节特写**：从一个小到可以被忽略的细节开始（"他的右手无名指上，一直戴着一枚银戒指。每次开会他转笔的时候，戒指会轻轻敲在桌上。"）
8. **一句话定义**：用一句话定义整篇文章要讲的那个东西（"所谓中年危机，不是没能力换工作了，是突然不知道换工作的意义是什么了。"）

**结尾补充手法**：
8. **轻收尾**：不升华不拔高，就停在该停的地方（"我把那本书放回了书架。下一页还折着，不知道什么时候会继续读。"）

## 10. 书摘原文引用规范 (Book Excerpt Reference)

适用于读书心得型文章。区分两种引用场景：

| 场景 | 语法 | 规则 |
|------|------|------|
| **段落级书摘**（诗、长段落原文，通常 ≥ 3 行） | `>> ` 前缀 | **逐字复制原文，禁止任何润色/改写/摘要化**。包括原作翻译的措辞、标点、分行都保持原样 |
| **一两句金句型引用** | 普通 `>` 引用 | 可自然融入正文，普通引用流 |

**`>> ` 使用示例**：

```markdown
鲁米那首「客栈」我读了很多遍。翻译得真好。

>> 做人就像是一家客栈。
>> 每个早晨，一位新的客人。
>>
>> 无论来的是谁，都要心存感激，
>> 因为每一位都是来自远方的向导。

每次读到「远方的向导」那句，我都会停下来。
```

**关键规则**：
- `>> ` 块内的内容不经过冰清的润色流程，不参与语流自检
- `>> ` 块内的内容不受 AI 味审校（原文措辞风格是原作特征）
- `>>` 空行（不带文字）表示书摘内的段落分隔，会保留为 HTML 中的空行
- HTML 渲染为左边线暖色书摘区块（`border-left:3px solid #C8A96E; background:#FAF8F5`），与正文视觉区分
