# wechat-daily 写作框架参考 v2.5.0

> Agent 读完素材后，自问一句话找感觉：**这段素材里有没有一个画面/场景、一句触动你的话、一个从困惑到想通的过程？** 下面三种是**参考模式**，不是必须二选一/三选一的分类——素材完全可以同时带有多种模式的影子（比如一个场景里也藏着一次心路转变），不需要强行归为一类。
>
> **真正要产出的是一个具体的 3 拍框架**，写进 `Plan.md`：这篇文章第一拍写什么、第二拍写什么、第三拍写什么。参考模式怎么用、要不要融合，交给素材本身和 Agent 的判断，不需要用户裁决"这是哪一类"——句子从日记素材里来，不编不造。

## 通用底线（不管用哪种/几种参考模式都遵守）

- 不编造素材里没有的场景细节、对话、观点
- 不为制造叙事张力而放大情绪冲突（日记说"不太愿意"，就不要写成"一家人都不开心"）
- 不堆砌形容词，不滥用感官描写
- 不写成说教总结（"这告诉我们……"），不用「本质上」「干货」「说白了」等禁词
- **不用氛围做开头**：第一段从具体的人、动作或场景开始，不写「气氛紧张」「氛围很好」这类抽象判断。日记说了什么行为就写什么行为。氛围概括是给读者下结论，具体行为是让读者自己感受——永远选后者

## 结构连贯性：一篇文章只能有一个声音

写完 3 拍框架后自问一句：这三拍是从头到尾同一个人在说话吗？

**常见断裂模式**：
- 前两拍是"我看到了/想到了"，第三拍突然变成"你应该" → 人称和语气突变
- 第一拍是具体画面，第二拍直接跳到抽象概念罗列 → 叙事距离突变，读者跟不上
- 素材里有一段指令型内容（如"盘点自己""聚焦一个需求""从今天开始做调整"），被原封不动搬进文章 → 日记的对话对象是自己，文章的对话对象是读者，不转换就会像上课

**修复原则**：
- 如果素材同时有个人感受和指令型内容，选一条主线。指令型内容必须转换成"我在想/我在试"的个人思考口吻，不能直接对读者下指令
- 「轻提问收尾」和「行动指令」是两件事。前者是"我也有这个疑问，你呢？"，后者是"你应该做这个"
- 每一拍写完，回读第一拍——语气接得上吗？如果接不上，说明中间某拍跑了

## 篇幅原则

篇幅是**感觉**，不是数字。素材里只有一句话就写一句话，素材里有完整过程就写完整过程：

- **不要为了凑字数而展开**——写完该写的就停
- **不要因为感觉"差不多了"就截断**——素材里还有东西没说完就继续说

## 多种模式同时命中时怎么办

素材经常不止一条线。比如一篇陪孩子练琴的日记，既有具体的感官画面（闭眼听琴，脑后一阵发麻），又有一段从抵触到享受的心路转变——这种情况**不需要二选一**，把信息量更完整的那条线（通常是心路型）当主线框架，另一条线（画面细节）揉进主线的某一拍里当支撑细节即可。判断标准很简单：哪条线丢了会让这篇文章"缺了点什么"，哪条线就是主线；能被主线自然吸收的，就不用单独占一拍。

## 参考模式一：画面型

- **触发点**：一个具体的场景、画面、感官细节，让你停留了几秒
- **适用素材**：日常片段、日行一善、感官觉知、自然观察、身体感受、一个瞬间心里动了一下
- **建议框架**（3 拍，松散参考）：
  1. 画面本身——素材里那个场景/动作/感官细节，直接呈现
  2. 当下的感受或反应——心里动了一下，为什么动，一句话点到为止
  3. 停在感受里——不升华、不总结，日记里最后那个感受就是结尾
- **篇幅感觉**：短。一个画面，停在感受里就好
- **特有提醒**：别加「这让我想到……」的反思层（那是心路型的事），别把一个瞬间拖成一篇道理

## 参考模式二：引句型

- **触发点**：一句话/一段话触动了你——书里的、播客里的、电影台词，也可能是孩子说的一句话
- **适用素材**：读书分享、影视/播客金句、他人的一句话打动了你
- **建议框架**（3 拍，松散参考）：
  1. 引句或原话——素材里那句打动你的话，直接呈现（不超过 3 行，超过就喧宾夺主）
  2. 为什么触动你——个人连接，一句话说清楚，不写成书评（不介绍作者、背景、全书梗概）
  3. 带着这句话回到生活——这句话在脑子里转，是因为刚好撞上了最近在想的事；也可以留一个轻提问收尾
- **篇幅感觉**：中等。一段话 + 个人连接，比画面型多一层展开
- **特有提醒**：别写成书评/读后感，别从引句里总结人生道理（「这句话告诉我们……」）

---

## 参考模式三：心路型

- **触发点**：素材记录了一个从困惑/为难/新尝试，到想通/释然/发现了什么的心理过程
- **适用素材**：学习实践感悟、方法碎片、踩坑记录、陪伴家人/孩子时的观察与感悟、日行一善里带心理转变的部分
- **建议框架**（3 拍，松散参考）：
  1. 起点的状态——为难、抵触、不熟练、困惑，具体是什么样子
  2. 中间发生了什么——做了什么尝试、发现了什么，用「正在想」替代「想好了」
  3. 现在的状态变化——点到为止，不强行升华，坦承还在路上也可以
- **篇幅感觉**：中长。有过程就有长度，踩坑过程完整就写完整，别因为感觉"是不是太长了"就砍掉有用的细节
- **特有提醒**：别用「从…到…再到…最后…」的列举式总结，别写成教程（不说「你应该」「你需要」）
